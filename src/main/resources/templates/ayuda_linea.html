Preguntas frecuentes
Como crear una orden
  1. Haz clic en el boton Nueva Orden en la parte superior derecha de la lista.
  2. Selecciona el cliente y verifica sus datos de contacto.
  3. Elige los productos/servicios, cantidades y precios correspondientes.
  4. Define la fecha de entrega y la ciudad de envio.
  5. Añade una descripcion breve de la venta o notas para el equipo.
  6. Selecciona el estado inicial (ej. PENDIENTE) y revisa el total calculado.
  7. Presiona Guardar. Si todo esta correcto, veras la orden en la lista.
Como crear un producto
  1. Desde el menu lateral entra a Productos y presiona el boton Nuevo Producto.
  2. Ingresa nombre, categoria y descripcion breve.
  3. Define precio, cantidad disponibleuna imagen y la unidad de medida.
  4. Guarda para registrar el producto. Verifica que aparezca en el listado y que los datos sean correctos.
Como crear usuarios
  1. En el menu lateral, entra a Usuarios y haz clic en Crear.
  2. Define el tipo de usuario (Natural o Juridico). Para juridico, los campos de apellidos no se diligencian.
  3. Ingresa documento y nombre. Si es Natural, agrega primer y segundo apellido; si es Juridico, deja apellidos vacios.
  4. Usuarios Natural no se debe agregar usuario ni contraseña
  5. Completa correo, telefono, departamento y ciudad.
  6. Selecciona el rol y perfil si aplica, luego presiona Guardar.
  7. Verifica que el usuario aparezca en la lista y que los apellidos no existan para los juridicos.
